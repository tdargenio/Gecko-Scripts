# Privacy Policy for Customer Service Call Guide

**Effective date:** October 1, 2026  
**Last updated:** October 1, 2026

## Overview

Customer Service Call Guide is a Chrome extension designed to help authorized customer service agents quickly locate approved call guidance and copy the policy number displayed on an active, supported internal policy page.

The extension is designed to minimize access to data. It performs its functions locally in the user's browser and does not transmit policy information, website content, browsing activity, saved preferences, or copied word tracks to the developer or to an external server.

## Information the Extension Handles

### Active webpage content

When the user selects **Copy policy #**, the extension temporarily reads the active webpage to locate a policy number displayed on that page. This processing occurs locally in the browser and only after the user activates the feature.

The extension does not continuously monitor webpages. The extension does not retain the policy number after it has been copied, except that the number may remain temporarily in the user's operating-system clipboard according to the clipboard's normal behavior.

### Locally stored preferences

The extension uses Chrome extension storage to save the following preferences on the user's device:

- Light or dark theme selection
- Favorite word-track selections
- Recently copied word-track identifiers

These locally stored preferences do not include policy numbers, customer names, customer contact information, authentication credentials, payment information, or complete webpage content.

### Approved word tracks

The extension contains approved reference wording within the extension package. A user may temporarily edit the displayed wording before copying it. Those temporary edits are not transmitted externally and are not saved when another track is selected or the original text is restored.

## Information the Extension Does Not Collect or Transmit

The extension does not collect, sell, rent, share, or transmit:

- Policy numbers
- Customer names or contact details
- Financial or payment information
- Authentication credentials
- Health information
- Personal communications
- Browsing history
- Website content
- User activity for advertising or analytics
- Location information

The extension does not use analytics, advertising services, tracking pixels, cookies, or third-party data brokers.

## Permissions and Their Use

### `storage`

Used only to save extension preferences locally, including the selected theme, favorite word tracks, and recently copied word-track identifiers.

### `activeTab`

Used to obtain temporary access to the webpage currently selected by the user when the user requests the policy-number copy feature.

### `scripting`

Used to run a limited, user-initiated script in the active supported policy page to locate the policy number displayed in that page. The script does not modify policy data, submit forms, perform policy transactions, or transmit page content.

### `sidePanel`

Used to display the extension's call guide beside the active webpage so agents can reference approved wording without leaving the policy application.

### Host permissions

Access is limited to these supported internal domains:

- `https://edgecounselor.geico.net/*`
- `https://portco-pd.geico.net/*`

These permissions allow the user-initiated policy-number feature to operate on supported internal policy pages. The extension does not request access to all websites.

## Remote Code

The extension does not use remote code. All JavaScript, HTML, CSS, word-track content, and image assets required by the extension are included in the extension package. The extension does not download or execute external JavaScript or WebAssembly.

## Data Sharing and Sale

The extension does not sell user data. The extension does not share user data with third parties. The extension does not transfer data for advertising, creditworthiness, lending, or any purpose unrelated to the extension's single purpose.

## Data Security and Retention

The extension follows a data-minimization approach. Policy-page content is processed only as needed to complete a user-requested action. Policy numbers and webpage content are not placed in extension storage. Locally saved preferences remain in Chrome extension storage until the user clears extension data or removes the extension.

Users should continue to follow all applicable company security, privacy, access-control, and customer-information-handling requirements when using the extension.

## Children's Privacy

The extension is a workplace productivity tool intended for authorized business users. It is not directed to children and does not knowingly collect information from children.

## Changes to This Policy

This policy may be updated when the extension's functionality or data practices change. Material changes will be reflected by updating the effective date and the published policy.

## Contact

For privacy questions, support requests, or concerns about this extension, contact the publisher through the support contact listed on the Chrome Web Store listing or the applicable internal support channel.
